A Christmas tree of green stars stands on its trunk above a greeting.
Coloured lights come on all over the tree one after another and go out
again, and the word CODE in the greeting flashes in the colour of the
newest light: "MERRY CHRISTMAS, And lots of CODE in" next year.

## Controls

- **Any key**: quit

## Options

From a terminal, `christbashtree es` shows the Spanish tree: "FELICES
FIESTAS, Y mucho CODIGO en" next year.

## History

Sergio Lepore wrote ChristBASHTree for Christmas 2014 as a short bash
script that drew with `tput`, run straight from the web with curl, and
others added to it until 2018. Asciiverse ported it to one small C
program with the same tree, lights and pace, so it runs on Windows too
and needs no bash; any key quits.
