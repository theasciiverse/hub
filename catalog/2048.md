The puzzle that took over 2014, in a plain terminal. Every move slides
all the tiles on the 4x4 board as far as they go in one direction, and
two tiles of the same number that run into each other merge into one
with their sum. After each move a new 2 (or now and then a 4) appears
in an empty cell. Keep merging up through 4, 8, 16 and on to 2048; the
game ends when the board is full and no move is left.

Each merge adds the new tile's value to your score, and a tile merges
only once per move. The usual plan is to keep the biggest tile in a
corner and build towards it, but the new tiles have a way of turning up
in the wrong place.

## Controls

- **Arrow keys**, **WASD**, **h j k l** or **4 8 6 2**: slide the tiles
- **r**: start again (asks first)
- **q**: quit (asks first)

At game over, **r** plays again and **q** quits.

## Options

- `2048 blackwhite`, `2048 whiteblack`, `2048 bluered`: other colour
  schemes for the tiles
- `2048 test`: runs the built-in tests of the sliding rules

## History

Gabriele Cirulli made 2048 in 2014 as an open-source web game, after
earlier games of the same kind. Maurits van der Schee wrote this
console version, 2048.c, the same year, in a single C file that draws
with ANSI escape codes and needs no libraries; it is packaged by Debian
and others. This edition waits at game over so the final board stays
in view, and is built for Windows as well.
