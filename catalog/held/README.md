# Held titles

Manifests and pages kept here are out of the catalog: neither build reads
this folder. Move a title's two files back to `catalog/` to list it again.

- **termcraft** (held 2026-11-03, David): it reproduces Minecraft's world
  under Minecraft's names (creepers, the Nether, the Ender Dragon), which
  are Mojang's. Its repo, preview cast and manifest are kept.
- **the-conception** (held 2026-11-14, David): Ondřej Žára's hex-cell
  roguelike on rotty, pulled from Asciiverse and GitHub before it was
  listed; its repo (theasciiverse/the-conception) is private again. Its
  preview cast is in that repo's `asciiverse/` folder.
